# Family Care — Frontend UI

This folder contains the UI codebase for **Family Care**, including HTML5 templates, CSS stylesheets, JavaScript interactions, and static assets.

## Directory Structure
- `templates/`: HTML5 views for landing, authentication, dashboard, family members, medical records, medicines, appointments, health analytics, AI predictions, and emergency SOS.
- `static/css/`: Main stylesheet (`main.css`) including Tailwind CSS utilities & visual styling.
- `static/js/`: Client-side interactive scripts (`main.js`).

## Usage
The HTML templates and static assets are served directly by the Django backend or can be developed independently using a standard live server.
